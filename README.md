# 꼬마 부기장 (Little Copilot)

> **차에서 말로 노는 우리 아이 부기장**
> 방향지시등, 와이퍼, 속도처럼 차에서 실제로 일어나는 일을 아이에게 음성 퀴즈로 들려주고, 아이가 말로 대답하며 이동에 참여하는 Pleos Connect 차량용 앱입니다.

## 이런 앱이에요

뒷좌석의 아이는 "아직 멀었어?", "이거 뭐야?" 하고 계속 말을 걸지만, 운전하는 보호자는 앞을 봐야 해서 대답하기 어렵습니다.

꼬마 부기장은 **차에서 지금 일어나는 일을 아이에게 질문으로 바꿔 줍니다.**

- 운전자가 깜빡이를 켜면 → "방금 똑딱 소리가 났어요. 기장님이 깜빡이를 켰나요?"
- 와이퍼가 켜지면 → "비가 오나 봐요! 와이퍼가 켜졌나요?"
- 차가 신호에 멈추면 → "내기해요! 금방 출발할까, 오래 기다릴까?"

질문은 **소리로만** 들려주고, 아이는 **말로** 대답합니다. 운전자는 화면을 만질 필요가 없고, 아이는 화면 대신 창밖과 차를 보게 됩니다. 아이 나이(5~6세 / 7~8세 / 9세 이상)에 맞춰 질문이 달라집니다.

## 실행 방법

### 1. 준비
- **Pleos Connect Emulator v2.1.0** 으로 가상 기기(AVD)를 만들고, **Cold boot** 로 실행합니다.
  (Quick boot로 켜면 차량 신호를 읽을 수 없습니다.)
- Pleos Playground 안내에 따라 에뮬레이터에 프로젝트 CRN을 등록합니다.
- 에뮬레이터 오른쪽 메뉴 `⋯` → **Microphone** 에서 PC 마이크 입력을 켭니다. (아이 대신 말로 대답하기 위해)
- 인터넷 연결이 필요합니다. (주행 기록 저장, 오늘의 미션 현황)

### 2. 앱 설치
```bash
adb install -r apk/차곡차곡_꼬마부기장_release.apk
```

### 3. 처음 실행하면
앱을 열면 아래 순서로 한 번만 설정합니다.

1. **차와 연결** — 자동으로 진행돼요
2. **권한 허용** — 차량 신호 읽기, 마이크
3. **보호자 동의** — 약관 3개 확인 후 [전체 동의]
4. **부기장 정보** — 아이 별명과 나이대 선택
5. **메인 화면** — 오늘 할 수 있는 미션과 진행률이 보여요

## 시연 방법 (약 10분)

에뮬레이터에서는 실제로 운전할 수 없어서, Pleos가 제공하는 **Virtual Console**(웹 화면)로 차를 움직이거나 깜빡이·와이퍼를 켭니다.

### Virtual Console 열기
1. 터미널에서 아래 명령을 실행합니다.
   ```bash
   adb forward tcp:8088 tcp:8088
   ```
2. PC 브라우저에서 **http://127.0.0.1:8088/** 을 엽니다.

Virtual Console 첫 화면에서 쓰는 곳
- 왼쪽 **ACCEL** (가속) / **BRAKE** (정지) 버튼
- 가운데 **SYSTEMS** 칸: 기어(GEAR), 앞 와이퍼(FRONT WIPER)
- 왼쪽 위 **Emulation Controls** → 검색창에 `Turn Signal` 입력 → 깜빡이

### 시연 순서

> 💡 아이가 지치지 않도록 **질문과 질문 사이에는 3분 쉬는 시간**이 있습니다. 한 질문이 끝나면 3분 뒤에 다음 단계를 진행해 주세요.

| 순서 | 이렇게 해 주세요 | 앱에서 일어나는 일 |
|---|---|---|
| 1 | 앱 메인 화면에서 **[부기장 출발!]** 을 누릅니다 | 부기장 모드가 켜져요 |
| 2 | Virtual Console에서 기어를 **D** 로 바꾸고 **ACCEL** 을 누릅니다 | 주행 화면으로 바뀌고 "부기장 출동! 준비됐어요?" 라고 물어요. 아무 말이나 대답하면 돼요 |
| 3 | (3분 뒤) Emulation Controls → **Turn Signal State** 에서 `Blink left` 를 눌렀다가 2~3초 뒤 `Off` | "깜빡이를 켰나요?" 라고 물어요. "응" 또는 "예"라고 대답해 보세요 |
| 4 | (3분 뒤) SYSTEMS → **FRONT WIPER** 를 `Low` 로 | "와이퍼가 켜졌나요?" 라고 물어요 |
| 5 | 와이퍼를 1분 이상 켜 둔 뒤 (3분 뒤) `Off` 로 | "와이퍼가 멈췄어요. 창밖이 맑아 보여요?" 라고 물어요 |
| 6 | **BRAKE** 를 눌러 차를 멈춥니다 | 멈춘 지 5초 뒤 "금방 출발할까, 오래 기다릴까?" 내기를 해요. 다시 **ACCEL** 로 출발하면 정답을 알려 줘요 |
| 7 | 기어를 **P** (주차)로 바꿉니다 | "도착! 오늘 ○개 중에 ○개 맞혔어요!" 오늘의 리포트를 들려준 뒤, 이번 주행 결과 화면으로 넘어가요 |
| 8 | 결과 화면에서 **[메인으로]** | 메인 화면의 "오늘의 미션" 진행률이 올라가 있어요 |

질문이 나오면 화면에 "듣고 있어요"가 표시됩니다. 이때 PC 마이크로 대답하면 됩니다. 대답이 없거나 틀려도 부기장이 친절하게 정답을 알려 줍니다.

## 미션 13가지

차의 어떤 상황에서 어떤 질문을 하는지 정리했습니다. (대표 질문은 7~8세 기준)

| 미션 | 언제 나오나요 | 이렇게 물어요 | 에뮬레이터 시연 |
|---|---|---|---|
| 부기장 출동 | 출발할 때 | "부기장 출동! 준비됐어요?" | ✅ |
| 깜빡이 소리 | 깜빡이를 켰다 끄면 | "기장님이 깜빡이를 켰나요?" | ✅ |
| 깜빡이 배우기 | 그날 첫 깜빡이 퀴즈 뒤 | "깜빡이는 누구한테 알려주는 불일까?" | ✅ |
| 깜빡이 기억 게임 | 깜빡이를 4번 이상 켜고 멈추면 | "왼쪽 깜빡이를 더 많이 켰을까?" | ✅ |
| 비 오는 날 | 와이퍼가 켜지면 | "와이퍼가 켜졌나요?" | ✅ |
| 비가 그쳤어요 | 와이퍼를 1분 이상 쓰다 끄면 | "창밖이 맑아 보여요?" | ✅ |
| 빠를까 느릴까 | 일정한 속도로 30초 달리면 | "우리 차는 빠를까, 느릴까?" | ✅ |
| 빨라졌을까 느려졌을까 | 속도가 크게 바뀌면 | "아까보다 빨라졌을까?" | ✅ |
| 신호 대기 | 멈추고 10초가 지나면 | "지금 신호등 불이 보여요?" | ✅ |
| 기다리기 내기 | 멈추고 5초가 지나면 | "금방 출발할까, 오래 기다릴까?" | ✅ |
| 오늘의 리포트 | 주차(P)하면 | "오늘 ○개 중에 ○개 맞혔어요!" | ✅ |
| 다음 회전 | 내비 안내에서 곧 꺾을 때 | "왼쪽일까, 오른쪽일까?" | ❌ 실차 필요 |
| 곧 도착 | 도착 5분 전 | "기장님께 뭐라고 말할까요?" | ❌ 실차 필요 |

> **다음 회전, 곧 도착** 미션은 내비게이션 길 안내 정보가 필요합니다. 에뮬레이터에서는 차를 움직여도 내비 위치가 따라 움직이지 않아 시연되지 않습니다. 실제 차량에서 경로 안내 중일 때 동작합니다.

## 안전을 위해 지킨 것

- **주행 중에는 화면을 조작할 수 없어요.** 설정 화면 등은 "주행 중이에요" 안내로 잠기고, 멈추면 풀립니다.
- **질문은 소리로만** 들려주고, 화면에는 짧은 상태만 보여 줍니다.
- 깜빡이가 켜져 있거나, 내비가 안내 중이거나, 곧 꺾어야 할 때는 질문을 **잠시 미룹니다.**
- 질문 사이에는 **3분 간격**을 두고, 대답을 3번 연속 못 알아들으면 그 주행에서는 쉽니다.
- 아이 목소리는 인식한 뒤 바로 버리고, 서버에는 별명·나이대·미션 결과만 저장합니다.

| 에뮬레이터 | Pleos Connect Emulator v2.1.0 (Android API 34) |
